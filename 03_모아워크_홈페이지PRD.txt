홈페이지 제작 기획서 PRD

[회사명]
모아워크

[프로젝트 개요]
온라인 판매를 준비하는 소상공인을 위한 모아워크의 소개, 서비스 안내, 문의 접수 준비를 제공하는 반응형 원페이지 웹사이트 구축

[주요 고객과 방문 목적]
주요 고객: 온라인 판매를 시작하거나 제품 소개 자료를 정리하려는 소상공인
방문 목적: 모아워크에서 제공하는 콘텐츠 제작 항목을 이해하고 상담을 준비한다.

[화면별 구성]
1. 메인: 대표 문구(좋은 제품이 온라인에서도 잘 전해지도록.), 소개 문구(소상공인을 위한 상세페이지·제품사진·소개글 제작), '상담 준비하기' 버튼(클릭 시 문의 영역으로 스크롤 이동), 이미지는 색상과 도형 요소로 대체 배치
2. 회사 소개: 대표가 상담과 제작을 직접 맡는 1인 스튜디오 특징 및 기존 자료를 먼저 확인한 뒤 필요한 작업을 제안한다는 내용 안내
3. 서비스: 3가지 핵심 서비스 카드 배치(상세페이지 제작 — 제품 특징 정리 / 제품사진 촬영 — 온라인 소개용 사진 / 브랜드 소개글 작성 — 이해하기 쉬운 소개 문장), 이미지는 공개 가능한 제품사진 확인 전까지 대체 그래픽 적용
4. FAQ: 아코디언 형태의 질문·답변 구성(Q1. 사진과 글도 함께 맡길 수 있나요? A1. 상세페이지·사진·소개글을 함께 구성할 수 있습니다. / Q2. 비용과 기간은? A2. [확인 필요] 사업체 확인 후 공개.)
5. 문의: 상담 준비 안내 문구(소개할 제품, 주요 고객, 현재 가진 자료, 필요한 제작 항목 정리 안내) 및 문의 입력 폼(이름, 연락 방법, 문의 내용 입력 필드, 전송 버튼) 배치

[고객 흐름]
메인 방문 및 대표 문구 확인 → 회사 소개 및 차별점 확인 → 3가지 서비스 내용 탐색 → FAQ 확인 → '상담 준비하기' 버튼 클릭 또는 하단 이동을 통한 문의 입력 폼 도달 → 문의 정보(이름, 연락 방법, 문의 내용) 입력 및 필수 항목 유효성 검사 통과

[필수 기능]
1. 메뉴 영역 이동: 상단 네비게이션 메뉴 및 메인 버튼 클릭 시 해당 섹션(메인, 회사 소개, 서비스, FAQ, 문의)으로 부드럽게 스크롤 이동
2. FAQ 아코디언 토글: 질문 클릭 시 답변 영역이 열리고 닫히는 기능
3. 반응형 웹 디자인: PC와 모바일 화면 해상도에 맞춰 레이아웃이 유연하게 변환되는 기능
4. 문의 폼 유효성 검사: 이름, 연락 방법, 문의 내용의 필수 입력 여부를 검사하고 누락 시 안내 메시지를 띄우는 기능

[개발 조건과 구현 단계]
개발 조건: HTML, CSS, JavaScript를 사용한 가볍고 단순한 단일 페이지(원페이지) 구조 구현
구현 단계: 2일차에는 전체 화면 마크업, 스타일링, 메뉴 이동, FAQ 토글, 모바일 반응형 처리, 문의 입력값 필수 검증 스크립트까지만 구현함. 실제 데이터 전송 및 백엔드 저장 연동은 3일차에 진행하며, 2일차에는 실제 저장이 되지 않으므로 '접수 완료'로 처리하지 않고 '입력 검증 완료 및 3일차 연동 예정' 안내 상태를 유지함. 결제, 회원가입, 복잡한 예약 시스템은 개발 범위에서 제외함.

[완료 기준]
1. 상단 메뉴나 메인의 '상담 준비하기' 버튼을 눌렀을 때 문의 영역으로 정확하게 화면이 스크롤 이동하는지 확인
2. FAQ 항목을 클릭했을 때 답변이 정상적으로 펼쳐지고 다시 누르면 접히는지 확인
3. 모바일 화면 폭(360px~768px)과 PC 화면 폭에서 요소가 깨지지 않고 의도한 순서대로 반응형 배치가 되는지 확인
4. 문의 폼에서 빈칸을 두고 버튼을 눌렀을 때 필수 입력 안내 경고가 정상적으로 뜨는지 확인
5. 필수 항목을 모두 적절히 입력하고 버튼을 눌렀을 때 유효성 검사를 통과하며 미연동 상태임을 명확히 인지할 수 있는지 확인

[미확인 사항]
1. 가격 체계, 표준 제작 기간, 수정 횟수, 파일 및 저작권 조건은 대표자 확인 필요
2. 서비스 영역에 사용할 실제 제품 사진 및 사진 사용 권한 보유 여부 확인 필요
